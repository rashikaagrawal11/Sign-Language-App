# 📌 SignBridge – ISL Learning & Translation Platform

SignBridge is an interactive and gamified platform designed to make Indian Sign Language (ISL) learning accessible, engaging, and practical. It combines structured learning, multilingual translation, and AI-assisted gesture recognition (prototype) to bridge communication gaps.

## 🚀 Features

- Interactive Learning Interface  
  Step-by-step visual lessons to help beginners easily learn ISL.

- Multilingual AI Translator  
  Converts text/voice ↔ sign language in English, Hindi, and Gujarati.

- Gamified Practice Experience  
  Quizzes, flashcards, streaks, XP, and rewards to keep users engaged.

- Camera-Based Sign Detection (Prototype)  
  Uses OpenCV-based model to capture gestures and simulate sign recognition.

- Structured Learning Modules  
  Covers alphabets, numbers, words, and commonly used phrases.

- Progress Tracking & Emergency Support  
  Tracks user performance and provides quick access to essential emergency signs.

## ⚙️ Setup & Installation

1. Clone the repository:
   git clone https://github.com/your-username/signbridge.git

2. Install dependencies:
   pip install opencv-python numpy

3. Run the ML detection:
   python app.py

4. Open index.html in your browser

5. (Optional) Run colab_prediction.ipynb in Google Colab

## ⚠️ Note

The gesture recognition system is a prototype and may not be fully accurate in real-time conditions.
